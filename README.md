# Diabetes Prediction Using Least Squares Method

## Project Overview
This project uses Machine Learning to predict whether a patient has diabetes or not using the Pima Indians Diabetes Dataset.

## Algorithm Used
- Linear Regression (Least Squares Method)

## Dataset
Pima Indians Diabetes Dataset from Kaggle.

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Model Evaluation
The model is evaluated using:
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## Visualizations
1. Confusion Matrix
2. Model Performance Evaluation
3. Actual vs Predicted Values

## How to Run
1. Download the notebook.
2. Open it in Google Colab.
3. Upload the Kaggle dataset ZIP file.
4. Run all cells sequentially.
